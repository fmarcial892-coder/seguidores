# Seguidores do Instagram

Plataforma web gratuita para organizar consultas de informações públicas de perfis.

## Arquivos
- index.html — interface
- style.css — layout responsivo
- app.js — navegação, histórico e exportação CSV

## Importante
Esta versão é um frontend funcional. Ela não faz login no Instagram, não acessa contas privadas e não inventa e-mails ou telefones. Para dados públicos reais em escala, é necessário conectar uma fonte/API que permita esse uso.

## Publicação
Pode ser publicada como site estático no GitHub Pages, Netlify ou serviço semelhante.
